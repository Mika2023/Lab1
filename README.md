## Задание 1

### 1. Перейти в папку:
```
cd task1
```

### 2. Скомпилировать:
```
gcc -O2 mandelbrot.c -o mandelbrot -pthread -lm
```

### 3. Запустить:
```
./mandelbrot [число_потоков] [число_точек]
```

### 4. Тест:
```
bash benchmark_mandelbrot.sh
```
